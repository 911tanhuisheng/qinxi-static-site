# Moonlight 2077 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the static deployment test with a mobile-first Vue 3 cinematic Mid-Autumn experience.

**Architecture:** Vite compiles a Vue Composition API app. A Canvas background handles ambient visuals while semantic scene components expose interaction and copy; CSS handles responsive layout and progressive animation.

**Tech Stack:** Vue 3, Vite, TypeScript, Canvas 2D, CSS.

**Spec:** `docs/superpowers/specs/2026-09-25-moonlight-2077-design.md`

## Global Constraints

- Use Vue 3 + Vite + TypeScript with no heavy UI framework.
- Publish only built `dist/` output through the existing GitHub Pages workflow.
- Optimize 375×812 through 430×932 first, preserve reduced-motion access.
- Avoid red/gold festival-template imagery and external image dependencies.

## Review Focus

- Canvas must destroy event listeners and animation frames on component unmount.
- Empty blessings must not render as a successful wish.
- Narrow mobile views must not create horizontal scrolling.
- Reduced-motion users must receive a readable static experience.
- Build output must retain an `index.html` at its root.
